Forge once with Opus, run with Haiku

Three environments: a quirky internal inventory API, call-graph questions over a 120-module codebase, and support triage behind a signed API. Each is worked on in four fresh sessions, each with a different question. trod forge built a library for each environment once, with Opus 5.5 (about $0.85). Sessions then ran with that library: the library cards are in the system prompt and trod_eval runs code mode. They are compared with sessions that start from scratch.

Haiku 5.5 with the forged library got every answer right in all 9 runs. Sonnet 5.5 from scratch did so in 6 of 9, and missed call-graph answers in every code-qa run. Haiku did it at 5–14% of Sonnet's cost, with 0.21–0.69× the tokens and 1.3–6× faster than Haiku from scratch. The forge pays for itself after about 12–22 sessions. Sonnet also improves with the library (0.46× tokens on the inventory API, 0.88 → 1.00 score on code-qa), except on ticket-triage, where writing a 30-line client is cheaper than learning six tools (1.32× tokens).
