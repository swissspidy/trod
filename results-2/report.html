Round 2: within a session

trod 0.2 brings single-file tools, a validation hook, the permanent trod_run tool and the format in the system prompt. With it, agents built tools unprompted in 16 of 18 sessions (round 1: 1 of 24). Forced tool building fell from 1.84× to 1.25× baseline tokens, and reached parity on ticket-triage (0.97×). A tool still cannot beat a script within one session, because both are written once and re-run. The library arm (tools from an earlier run) was the only arm with no failures.

The next two pages show where tools pay off: a cheaper model using a stronger model's tools (Haiku: 0.64× tokens, 0.23× on code-qa), and a library built once for many fresh sessions (0.74× tokens per session, break-even after about 12 sessions). Full write-up: results-2/README.md.
